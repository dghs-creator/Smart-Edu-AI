    Chapter 15. 나만의 AI 학습 포트폴리오 만들기¶

    🎯 이 장의 학습 목표¶

    • 지금까지 만든 프롬프트·결과물을 선별하여 포트폴리오 문서로 정리할 수 있다
    • 각 결과물에 자기 성찰 코멘트를 붙여 의미 있는 학습 기록을 만들 수 있다
    • NotebookLM에 포트폴리오를 업로드하여 나만의 학습 지식 베이스를 완성할 수 있다

    예상 학습 시간: 약 50분

    📚 미리 알아야 할 것¶

    지난 14차시까지 여러분은 ChatGPT, Gemini, NotebookLM 등 AI 도구를 활용해 요약, 보고서, 발표 자료 등 다양한 결과물을 만들어왔어요. 이번 시간에는 그 모든 경험을 하나의 문서로 엮습니다. 특별한 기술이 필요하지 않아요. 필요한 건 돌아보는 시간과 정리하는 습관뿐입니다. 😊

    📚 핵심 개념¶

    개념 1: 학습 포트폴리오¶

    1. 비유로 시작: 학습 포트폴리오는 마치 요리사의 레시피 북과 같아요. 단순히 완성된 요리 사진만 모아두는 것이 아니라, "이 재료를 왜 넣었는지", "다음엔 어떻게 바꿔볼지"까지 적어두는 노트입니다.

    2. 정확한 정의: 학습 포트폴리오란 학습 과정에서 만든 결과물을 선별하고, 각 결과물에 대해 무엇을 배웠는지 성찰 코멘트를 붙여 정리한 문서입니다.

    3. 예시로 확인 ·1) ❌ 단순 모음: "3차시 요약문.txt, 7차시 보고서.docx…" → 파일만 나열
      ·2) ✅ 포트폴리오: "3차시 요약문 + 이 프롬프트가 효과적이었던 이유 + 다음에 개선할 점"

    개념 2: 자기 성찰 코멘트¶

    1. 비유로 시작: 자기 성찰 코멘트는 마치 일기장의 한 줄 소감과 같아요. "오늘 뭘 했는지"보다 "오늘 뭘 느꼈고, 다음엔 어떻게 할지"가 핵심이에요.

    2. 정확한 정의: 결과물 하나하나에 붙이는 짧은 글로, 다음 세 가지를 담습니다. ·1) 무엇을 했는가 (사용한 도구·프롬프트)
      ·2) 무엇이 좋았는가 / 아쉬웠는가
      ·3) 다음엔 어떻게 하겠는가

    3. 예시로 확인

    "NotebookLM에 논문 3편을 올리고 비교 요약을 요청했다. AI가 공통 키워드를 잘 뽑아줬지만, 각 논문의 한계점 비교는 내가 직접 보완해야 했다. 다음엔 '각 논문의 한계를 비교해줘'라는 후속 프롬프트를 추가하겠다."

    💡 잠깐! "성찰"이라고 하면 거창하게 느껴질 수 있지만, 2~3문장이면 충분해요. 완벽할 필요 없습니다!

    🔨 따라하기¶

    아래 5단계를 순서대로 따라가면, 이 시간이 끝날 때 나만의 AI 학습 포트폴리오 문서 1개와 NotebookLM 지식 베이스 1개가 완성됩니다.

    Step 1: 결과물 목록 만들기 (10분)¶

    지금까지 각 차시에서 만든 결과물을 빠르게 훑어보세요. 모든 것을 넣을 필요 없습니다. "이건 잘했다" 또는 "이건 많이 배웠다" 싶은 것 5~7개만 고르세요.

    ChatGPT에 아래 프롬프트를 입력하면 정리 틀을 받을 수 있어요.

    프롬프트: 

    나는 AI 활용 학습 과정(총 16차시)을 수강 중이야.
각 차시에서 만든 결과물을 포트폴리오로 정리하려 해.
아래 형식으로 빈 템플릿을 만들어줘.

형식:
- 차시 번호 / 제목
- 선택한 결과물 이름
- 사용한 AI 도구
- 핵심 프롬프트 (1개)
- 자기 성찰 코멘트 (좋았던 점 / 아쉬운 점 / 다음 계획)

총 7개 항목 분량의 빈 템플릿을 만들어줘.

    실행 결과 (예시): 

    ## 나의 AI 학습 포트폴리오

### 결과물 1
- 차시: ___차시 / 제목: ___
- 결과물: ___
- 사용 도구: ___
- 핵심 프롬프트: "___"
- 성찰 코멘트
  - 좋았던 점: ___
  - 아쉬운 점: ___
  - 다음 계획: ___

### 결과물 2
(동일 구조 반복...)

    ✅ 체크포인트: 빈 템플릿이 생성되었다면 성공이에요!

    Step 2: 베스트 결과물 선별 & 템플릿 채우기 (15분)¶

    이제 실제로 템플릿을 채워봅시다. 아래 기준으로 5~7개를 고르세요.

    • 기준 1: 프롬프트를 여러 번 다듬어 좋은 결과를 얻은 것
    • 기준 2: 처음엔 실패했지만 개선해서 성공한 것
    • 기준 3: 실생활이나 업무에 바로 써먹은 것

    채우기 예시: 

    ### 결과물 1
- 차시: 5차시 / 프롬프트 체인으로 보고서 쓰기
- 결과물: "AI 윤리 동향 보고서" (800자)
- 사용 도구: ChatGPT
- 핵심 프롬프트: "AI 윤리에 대한 최근 이슈를 3가지로 
  나누고, 각 이슈의 찬반 논점을 정리해줘"
- 성찰 코멘트
  - 좋았던 점: 프롬프트를 단계별로 나누니 구조가 명확해짐
  - 아쉬운 점: 출처 확인을 별도로 해야 했음
  - 다음 계획: 출처 요청 프롬프트를 체인에 추가하겠음

    💡 팁: 성찰 코멘트는 각각 1문장이면 됩니다. 부담 갖지 마세요!

    Step 3: 포트폴리오 서문 작성하기 (5분)¶

    포트폴리오 맨 앞에 짧은 자기소개와 학습 여정 요약을 넣으면 완성도가 높아져요.

    프롬프트: 

    나는 AI 도구 활용법을 16차시에 걸쳐 독학한 학습자야.
아래 내용을 반영해서 포트폴리오 서문(150자 내외)을 써줘.

- 학습 기간: 약 8주
- 주로 사용한 도구: ChatGPT, NotebookLM
- 가장 큰 변화: 프롬프트를 구체적으로 쓸수록 
  결과가 좋아진다는 걸 체감함

    실행 결과 (예시): 

    ## 서문
이 포트폴리오는 약 8주간 AI 활용 학습 과정을 독학하며 
만든 결과물 모음입니다. ChatGPT와 NotebookLM을 주로 
사용했으며, "프롬프트의 구체성이 결과의 질을 결정한다"는 
핵심 원칙을 체득한 과정을 담았습니다.

    ✅ 체크포인트: 서문까지 완성했다면, 포트폴리오 문서가 거의 다 된 거예요! 🎉

    Step 4: 하나의 문서로 합치기 (5분)¶

    서문 + 결과물 1~7을 하나의 문서에 순서대로 붙여넣으세요. 파일 형식은 자유입니다.

    • Google Docs 또는 Word: 가장 편리
    • Markdown(.md): 개발자라면 이것도 좋아요
    • PDF 변환: 나중에 공유할 때 유용
    flowchart LR A["📝 서문"] --> B["⭐ 결과물 1~7\n+ 성찰 코멘트"] B --> C["📄 하나의 문서로 합치기"] C --> D["☁️ NotebookLM\n업로드"]

    Step 5: NotebookLM에 업로드하여 지식 베이스 완성 (10분)¶

    마지막 단계입니다! 완성한 포트폴리오를 NotebookLM에 올려서 나만의 학습 지식 베이스를 만들어요.

    1. NotebookLM(notebooklm.google.com)에 접속합니다
    2. 새 노트북 만들기를 클릭합니다
    3. 노트북 이름을 "나의 AI 학습 포트폴리오"로 지정합니다
    4. 소스 추가 → 완성한 포트폴리오 문서를 업로드합니다
    5. 업로드 후 아래 질문을 던져보세요

    NotebookLM에 물어볼 질문 예시: 

    내 포트폴리오에서 가장 자주 등장하는 프롬프트 전략은 뭐야?


    내가 반복적으로 아쉬워한 점은 어떤 패턴이 있어?

    내 학습 여정을 3단계로 요약해줘.

    ✅ 체크포인트: NotebookLM이 여러분의 포트폴리오 내용을 바탕으로 답변한다면 성공입니다! 이제 여러분만의 학습 자산이 만들어진 거예요. 🏆

    💡 잠깐! 여기까지 오셨다면 정말 대단합니다! 15차시 동안 쌓아온 경험이 하나의 문서로 정리된 순간이에요. 👏

    ⚠️ 주의할 점¶

    1. "전부 다 넣어야 한다"는 부담을 버리세요 포트폴리오의 핵심은 선별입니다. 내용 전부를 넣으면 오히려 초점이 흐려져요. "이걸 왜 골랐는지"를 설명할 수 있는 5~7개면 충분합니다.

    2. 성찰 코멘트를 건너뛰지 마세요 결과물만 모아두면 단순 파일 모음이 됩니다. 1문장짜리 성찰이라도 꼭 붙이세요. 그 1문장이 3개월 후 여러분에게 "아, 그때 이렇게 했었지!"라는 귀중한 기억을 되살려줍니다.

    ✅ 점검하기¶

    1. 학습 포트폴리오와 단순 파일 모음의 가장 큰 차이는 무엇인가요?

    정답 확인 학습 포트폴리오는 결과물에 자기 성찰 코멘트(좋았던 점, 아쉬운 점, 다음 계획)가 붙어 있다는 점이 단순 파일 모음과 다릅니다. 성찰이 있어야 "기록"이 "학습 자산"이 됩니다.

    2. NotebookLM에 포트폴리오를 업로드하면 어떤 활용이 가능해지나요?

    정답 확인 과거 학습 기록을 기반으로 AI에게 질문할 수 있습니다. 예를 들어 "내가 자주 사용한 프롬프트 전략"이나 "반복된 아쉬운 점의 패턴"을 AI가 분석해주므로, 앞으로의 학습 전략을 세우는 데 활용할 수 있습니다.

    3. 포트폴리오에 넣을 결과물을 고를 때 좋은 기준 2가지를 말해보세요.

    정답 확인 ① 프롬프트를 개선해서 좋은 결과를 얻은 것, ② 처음엔 실패했지만 수정 과정에서 많이 배운 것 (또는 실생활에 바로 활용한 것)

    📌 이 장의 핵심 정리¶

    • ✅ 학습 포트폴리오 = 선별된 결과물 + 자기 성찰 코멘트
    • ✅ 성찰 코멘트는 좋았던 점 / 아쉬운 점 / 다음 계획 3요소로 구성
    • ✅ NotebookLM에 업로드하면 과거 학습을 검색·분석 가능한 지식 베이스로 활용 가능
