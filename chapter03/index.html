    Chapter 03. 개념 사이의 연결고리 찾기 – 비교·관계·구조화 질문법¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 아래 내용을 할 수 있습니다.

    • 개별 개념을 넘어 개념 간 관계를 파악하는 질문을 설계할 수 있다
    • AI에게 비교 정리, 마인드맵 형태로 출력을 요청하는 프롬프트를 작성할 수 있다
    • ChatGPT와 Gemini의 구조화 스타일 차이를 이해하고 상황에 맞게 선택할 수 있다

    예상 학습 시간: 약 50분

    📚 미리 알아야 할 것¶

    지난 장(Chapter 02)에서 우리는 하나의 개념을 깊이 파고드는 질문법을 연습했어요. "이게 뭐야?", "예시를 들어줘" 같은 프롬프트로 개별 개념을 이해하는 방법이었죠.

    이번 장에서는 한 단계 더 나아갑니다. 개념 하나가 아니라, 개념 둘 이상을 놓고 그 사이의 관계를 AI에게 물어보는 거예요.

    📚 핵심 개념¶

    핵심 개념 ❶: 비교 질문법¶

    1. 비유로 시작해 볼게요 🍎🍊

    비교 질문은 마치 두 과일을 나란히 놓고 살펴보는 것과 같아요. 사과와 오렌지를 각각 따로 보면 "둥글다, 맛있다" 정도만 알지만, 나란히 놓으면 "껍질 두께가 다르다, 즙의 양이 다르다" 같은 차이점이 보이기 시작합니다.

    2. 정확한 정의

    비교 질문법이란, 헷갈리거나 관련 있는 두 개 이상의 개념을 함께 제시하고, AI에게 공통점·차이점·관계를 정리해달라고 요청하는 질문 방식입니다.

    3. 예시로 확인

    혼자 공부할 때 이런 경험 있지 않나요?

    • "확산이랑 삼투… 둘 다 농도 관련인데 뭐가 다르지?"
    • "자본주의랑 사회주의, 시험에 비교 문제 나올 것 같은데…"
    • "TCP와 UDP, 둘 다 프로토콜인데 언제 뭘 쓰지?"

    이런 순간이 바로 비교 질문법이 필요한 타이밍이에요!

    💡 기억하세요! 헷갈리는 개념이 2개 이상 떠오르면, 그건 비교 질문을 던질 최적의 순간입니다.

    핵심 개념 ❷: 구조화 질문법¶

    1. 비유로 시작해 볼게요 🗂️

    구조화 질문은 마치 서랍장 정리와 같아요. 공부한 내용이 방바닥에 흩어진 물건들이라면, 구조화 질문은 "큰 서랍 → 중간 칸 → 작은 칸" 순서로 분류해달라고 AI에게 요청하는 거예요.

    2. 정확한 정의

    구조화 질문법이란, 여러 개념을 계층(상위↔하위), 분류(카테고리별), 관계(원인↔결과) 형태로 정리해달라고 요청하는 질문 방식입니다. 마인드맵, 계층 목록, 흐름도 등의 형태로 결과를 받을 수 있어요.

    3. 예시로 확인

    "생물 분류 단원에서 나온 개념들을 상위→하위 순서로 정리해줘"처럼 요청하면, AI가 다음과 같은 형태로 답해줍니다.

    • 생물 분류 → 계(界) → 문(門) → 강(綱) → 목(目) → 과(科) → 속(屬) → 종(種)

    흩어져 있던 개념이 한눈에 들어오죠?

    💡 잠깐! 여기까지 이해가 잘 되셨나요? 비교 질문 = "A와 B의 차이", 구조화 질문 = "전체를 체계적으로 정리" 이 두 가지만 기억하면 됩니다. 천천히 다시 읽어봐도 괜찮아요! 😊

    🔨 따라하기 실습¶

    이제 ChatGPT와 Gemini에 직접 프롬프트를 입력해 봅시다!

    Step 1: 비교 질문 프롬프트 작성하기¶

    먼저 헷갈리는 개념 쌍을 하나 골라보세요. 여기서는 "확산과 삼투"를 예시로 사용합니다.

    ChatGPT에 입력할 프롬프트:

    나는 중학교 과학을 독학하는 학생이야.
"확산"과 "삼투"가 헷갈려.

다음 기준으로 둘을 비교해서 정리해줘:
1. 정의
2. 이동하는 물질
3. 반투막 필요 여부
4. 일상 속 예시

비교가 한눈에 보이도록 깔끔하게 정리해줘.

    Gemini에도 같은 프롬프트를 입력해 보세요.

    ✅ 체크포인트: 두 AI 모두에서 답변을 받았나요? 아직 비교는 하지 말고, 일단 답변을 각각 저장해 두세요!

    Step 2: 두 AI의 답변 비교하기¶

    두 AI의 답변을 나란히 놓고 살펴보세요. 아래 기준으로 비교하면 쉬워요.

    • 정리 형식: 어느 쪽이 더 깔끔하게 구분했나요?
    • 예시의 질: 어느 쪽 예시가 더 이해하기 쉬웠나요?
    • 추가 정보: 어느 쪽이 내가 모르던 연결 정보를 더 알려줬나요?
    flowchart LR A["같은 프롬프트 작성"] --> B["ChatGPT에 입력"] A --> C["Gemini에 입력"] B --> D["답변 저장"] C --> E["답변 저장"] D --> F["나란히 비교!"] E --> F

    💡 팁! ChatGPT는 비교 항목을 체계적으로 나누는 데 강한 편이고, Gemini는 최신 사례나 부가 맥락을 연결해주는 데 강한 편이에요. 직접 확인해 보세요!

    Step 3: 구조화 질문 프롬프트 작성하기¶

    이번에는 한 단원 전체를 구조화해 봅시다.

    ChatGPT에 입력할 프롬프트:

    중학교 과학 "물질의 상태 변화" 단원의 핵심 개념들을
마인드맵 형태로 정리해줘.

- 중심 주제를 가운데 두고
- 큰 가지(대분류) → 작은 가지(세부 개념) 순서로
- 각 개념 옆에 한 줄 설명도 붙여줘
- 들여쓰기 목록 형태로 보여줘

    실행 결과 예시:

    물질의 상태 변화
├── 물질의 세 가지 상태
│   ├── 고체: 모양과 부피가 일정
│   ├── 액체: 모양은 변하고 부피는 일정
│   └── 기체: 모양과 부피 모두 변함
├── 상태 변화의 종류
│   ├── 융해: 고체 → 액체
│   ├── 기화: 액체 → 기체
│   ├── 승화: 고체 ↔ 기체
│   ├── 응고: 액체 → 고체
│   └── 액화: 기체 → 액체
└── 상태 변화와 열에너지
    ├── 흡열 변화: 융해, 기화, 승화(고→기)
    └── 발열 변화: 응고, 액화, 승화(기→고)

    Gemini에도 같은 프롬프트를 넣어보고, 구조가 어떻게 다른지 확인해 보세요.

    ✅ 체크포인트: 들여쓰기 목록 형태로 계층 구조가 나왔나요? "큰 분류 → 세부 개념"이 보이면 성공입니다!

    Step 4: 후속 질문으로 깊이 파고들기¶

    Step 1에서 받은 비교 결과 중 아직 헷갈리는 부분이 있다면, 후속 질문을 던져보세요.

    후속 질문 프롬프트 예시:

    위 비교에서 "반투막"이 정확히 뭔지 모르겠어.
반투막을 일상 속 비유로 설명해주고,
확산에서는 왜 반투막이 필요 없는지도 알려줘.

    이렇게 하면 비교 → 모르는 부분 발견 → 추가 질문이라는 학습의 선순환이 만들어져요.

    flowchart TD A["비교 질문 던지기"] --> B["AI 답변 받기"] B --> C{"이해 안 되는\n부분 있나?"} C -- 있다 --> D["후속 질문 던지기"] D --> B C -- 없다 --> E["✅ 개념 정리 완료!"]

    Step 5: 나만의 비교·구조화 프롬프트 만들기¶

    지금 공부하고 있는 과목에서 직접 적용해 보세요!

    비교 질문 템플릿:

    나는 [과목]을 독학하는 학생이야.
"[개념 A]"와 "[개념 B]"가 헷갈려.

다음 기준으로 비교 정리해줘:
1. 정의
2. [비교 기준 1]
3. [비교 기준 2]
4. 실생활 예시

초보자도 이해할 수 있게 쉽게 설명해줘.

    구조화 질문 템플릿:

    [과목]의 "[단원명]" 전체 핵심 개념을
마인드맵(들여쓰기 목록) 형태로 정리해줘.
- 대분류 → 중분류 → 세부 개념 순서로
- 각 개념 옆에 한 줄 설명 포함

    ✅ 체크포인트: 직접 프롬프트를 작성해서 AI에 입력해 보셨나요? 복사만 하지 말고, 본인의 과목과 개념으로 바꿔서 시도해 보는 것이 진짜 학습이에요! 💪

    ⚠️ 주의할 점¶

    1. 비교 기준을 직접 정해주세요

    "A와 B 비교해줘"라고만 하면 AI가 아무 기준이나 골라서 비교합니다. "정의, 특징, 예시 기준으로"처럼 기준을 명시하면 원하는 답이 나와요.

    2. AI의 구조화 결과를 100% 신뢰하지 마세요

    AI가 만든 마인드맵이나 비교 정리는 출발점이지 정답지가 아닙니다. 교과서나 신뢰할 수 있는 자료로 꼭 한 번 확인하는 습관을 들이세요.

    ✅ 점검하기¶

    1. 비교 질문과 단순 질문의 차이는 무엇인가요?

    정답 확인 단순 질문은 "확산이 뭐야?"처럼 **하나의 개념**을 묻는 것이고, 비교 질문은 "확산과 삼투의 차이가 뭐야?"처럼 **두 개 이상의 개념을 나란히 놓고** 공통점·차이점·관계를 묻는 것입니다.

    2. AI에게 구조화된 정리를 요청할 때, 프롬프트에 꼭 포함해야 할 요소 2가지는?

    정답 확인 ① **출력 형태 지정** (마인드맵, 계층 목록, 흐름도 등) ② **정리 순서 또는 기준 지정** (대분류→소분류, 시간순, 비교 기준 등) 이 두 가지를 명시해야 AI가 원하는 형태로 답변합니다.

    3. ChatGPT와 Gemini 중, 체계적 비교 정리에 상대적으로 강한 쪽은? 그리고 최신 사례 연결에 강한 쪽은?

    정답 확인 일반적으로 **ChatGPT**가 항목별 체계적 정리에 강하고, **Gemini**가 최신 정보나 실시간 검색 기반 사례 연결에 강한 편입니다. (다만 두 도구 모두 계속 발전하고 있으므로, 직접 비교해보는 습관이 가장 중요해요!)

    📌 이 장의 핵심 정리¶
